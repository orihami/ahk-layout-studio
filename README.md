# ⌨ AHK 配列スタジオ

AutoHotkey で作った自作キー配列を、**見て・ためして・ドラッグ＆ドロップで組み替えられる**ブラウザアプリです。
インストール不要。`dist/ahk-layout-studio.html` をダウンロードしてブラウザで開くだけで動きます（ファイルは外部に送信されません）。

## できること

### ⌨ キーボード画面（ためす＋つくる）
- **押しているキー**のボタン（V・M など）をクリック → そのキーを押しっぱなしにした状態の配列に切り替わる
- 左の**パレット**から部品（← / コピー / 記号 / 文字入力 / アプリ起動 …）をキーへ**ドラッグ** → いまの状態で割り当て
  - 例: 「V」を押した状態にして、「←」を J へ運ぶ → `v & j::Left`
- キー同士のドラッグ: 移動（相手に割り当てがあれば入れ替え）／**Ctrl+ドラッグ**でコピー
- キーを「レイヤーのボタン」へドラッグ → そのレイヤーへ移す／🗑 へドラッグ → 解除
- 「＋ レイヤーを作る」へキーをドラッグ → そのキーを押しながら使う新しいレイヤー（単押しは自動で元の文字を入力）
- 「＋ アプリ別」で、特定のアプリだけで動く割り当て（`#HotIf WinActive(...)`）
- キーをクリック → ためした結果がログに出る。右欄で動作の確認・編集。実キーボードでも操作可
- ↶ / ↷ で元に戻す・やり直し、🔒 編集ロックで「ためすだけ」に

### 🔬 くわしく画面
コンテキスト／レイヤーのツリー、全体マップ、一覧表、検索、ホットストリング。

### 💾 書き出し
元のファイルとの差分を確認して `.ahk`（AutoHotkey v2、UTF-8 BOM 付き、改行コードは元のまま）をダウンロード。

## しくみ（ハイブリッド方式）

`.ahk` の中を 2 つに分けて扱います。

```ahk
; ==== BEGIN 配列アプリ管理区画 (ahk-layout-studio) : この区画はアプリが書き換えます。… ====
; --- v レイヤー（v を押しながら） ---
$v:: {
    KeyWait("v")
    if (A_PriorKey = "v")
        Send("v")
}
v & j::Left
; ==== END 配列アプリ管理区画 ====

; ↓ 区画の外（手書き部分）は一切書き換えません
MyFunc() {
    ...
}
```

- **管理区画**: アプリが割り当てデータ（表）から毎回作り直す部分
- **手書き部分**: 元のファイルのまま。キーボード上では 🔒 付きで表示され、表示・ためす・ドラッグ編集が可能。
  手書きの定義を触ると、**その定義だけ**を管理区画へ自動で取り込みます（AHK の重複エラーを防ぐため）。
  「まとめて取り込む」で一括取り込みも可能。関数や積み重ね記法など、表にできないものは手書きのまま残ります。
- 読み込んだだけ・取り込んだだけでは**動作は変わりません**（テストで確認しています）。

## 開発

```
src/
  index.html        画面の外枠
  css/app.css       スタイル
  js/state.js       アプリ全体の状態
  js/keys.js        キー配置（JIS/US）・キー名の対応
  js/parser.js      .ahk の解析（v1/v2）
  js/meaning.js     出力の「意味」（例: Ctrl+C → コピー）
  js/model.js       割り当てデータ・取り込み・.ahk の生成・Undo
  js/derive.js      生成した .ahk を解析して表示用データにする
  js/resolve.js     押している状態から、動くホットキーを求める
  js/palette.js     パレットの部品
  js/view-studio.js キーボード画面（ためす＋つくる、ドラッグ＆ドロップ）
  js/view-detail.js くわしく画面
  js/app.js         起動・ファイル操作・書き出し
tools/build.mjs     src/ を 1 つの HTML（dist/）にまとめる
tests/e2e.cjs       ブラウザでの自動テスト（Playwright）
```

```bash
npm run build   # dist/ahk-layout-studio.html を作る
npm test        # ビルドしてテスト（Playwright が必要）
```

開発中は `src/index.html` を直接ブラウザで開いても動きます。
